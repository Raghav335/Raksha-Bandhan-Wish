#🎀 Happy Raksha Bandhan — Specially For Sister #

A beautiful and interactive Raksha Bandhan wishing card website created to celebrate the special bond between a brother and sister. ❤️

✨ Features

- 🎀 Animated Rakhi
- 🌸 Falling Petals Animation
- ✨ Glassmorphism UI
- 💖 Brother's Promises
- 💌 Personalized Wish Message
- 🎉 Confetti Celebration Effect
- 🖼️ Generate Personalized Card
- 📥 Download Card as PNG
- 📱 Responsive Design

🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- SVG
- Canvas API
- Canvas Confetti
- html2canvas

🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open "index.html" in your browser.

No backend or database is required.

🎯 Purpose

This project brings the traditional emotion of Raksha Bandhan into a modern digital experience with personalized wishes, animations, and a downloadable greeting card.
